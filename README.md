# string2fingerprint

`string2fingerprint` is a Rust library project for detecting malformed strings
using SIMD fingerprinting. AVX-512 VNNI is a candidate instruction set.

The repository currently contains a dependency-free library scaffold. The
fingerprinting algorithm, input contract, and public API are pending design.

See [Contributing](CONTRIBUTING.md) for the toolchain, checks, and review process,
and the [Security Policy](SECURITY.md) for private vulnerability reporting.
